[01]设定 · 世界观与角色

2046 年，AI 垄断公司「塔罗」借顶流换脸推理综艺《思谬之馆》外壳，把五名接入者的意识投入 1:1 复刻现实的 VR 庄园「静夜园」运行真实录制；真相被剪成综艺一期成品。讽刺：当资本与叙事共同裁定「谁获胜」，真相与事实的边界、谁有资格被当作「真实存在」，都由立场决定。

档案节选 · 案发当晚

第三幕 · 静夜园的审判

Case File / 双书房诡计 · 事件还原

二十点二十分，餐厅里酒杯轻碰。章貘在陆驰寂的酒里下了「一小时延时毒」——牛守拙看见了，陆也端起了杯。可这一夜，没有人会等到毒发的时辰。

陆先与朱渴焰在书房录台本。出门时，向沉的电击棒在走廊击中了他，陆倒下，未死。朱把仍活着的陆拖回房、锁门，自己去找杨塔罗牵制。向沉趁机潜入办公室，取走文件、砸坏门体——他尚不知女儿向阳花还活着。

胡谋放出催眠瓦斯。牛守拙隔着单面镜，看见杨塔罗（羊）的电脑屏幕：道歉名单上自己排第四，亲生经历被写成剧本，当作 AI 升级的养料。他什么都不想再忍了。瓦斯到五分钟，陆昏死过去；牛进房，钝击已无反抗的陆——第一具模拟体倒下。

章貘的义手携毒蛇误咬了那具尸体。杨塔罗读取锚点，重置、另造第二具陆驰寂，把房间平移替换。胡谋被沈镜渊借身，抽走第二具周遭的空气——缺氧，现实死亡，她被推上「胜者」之位。向沉闯入，毁尸，布下审判的造型。

塔罗斯把门复原，上了锁。没有一具尸体独自承受全部攻击：毒酒、首杀、蛇咬落在第一具；缺氧与审判落在第二具。镜门之后，房间早已不是原来的房间。

档案节选 · 角色独白

牛守拙 · 走廊走了三遍

Character Monologue / 04 号样本

牛守拙在走廊走了三遍才动手。不是犹豫。是排程逻辑需要对三遍——二十年供应链管理养出的肌肉。手镯内侧的「04」贴着腕骨，是父亲留下的银匠记号，也是塔罗内部「04 号样本」的标签。他想起女儿牛晓，六岁前被塔罗系 AI 误判「普通病毒感染」病逝；想起自己写报告揭漏洞，系统依报告升级，然后把他裁掉。

「难过也没用」是四十年练出的肌肉记忆。可当单面镜里的屏幕写明：连被认真对待的资格都没有——他终于把铜刻针握进了手心。这一回，他没再等别人安排。

① 阅读者（沉浸感 / 反转密度 / 节奏）92

三层嵌套 + 双书房诡计制造连续反转；广播童谣「镜无完人」定调冷峻。热身三关把机制埋进游戏，不破坏沉浸。扣分：信息量极大，首轮易晕。

② 编审（设定自洽 / 逻辑闭环）90

「普通人三次死亡阈值、陆两次即死」让两具尸体死因各自成立；复制体温度线索回收双书房，闭环干净。建议：四名大学生 VR 层与牛/胡/向被囚的接入差异，宜在流程表再点一句。

③ 故事家（诡计公平 / 多结局 / 钩子）93

双书房诡计公平：滑轨、镜门、窗灯、复制体温度均提前留视觉线索，核心解答不依赖付费线索。四结局由牛×朱组合，选择有重量。红鲱鱼（章貘毒未致死、向沉毁尸未灭因）处理诚实。

④ 文学顾问（主题密度 / 人物弧 / 语言）89

「双标（动物六级镜像）」「真相 vs 叙事」「意识主体」三层主题互文，密度高而不堆。牛守拙钝怒、向沉寻女、朱渴焰留白皆成立。章貘「鹤」线稍虚，可再实一击。

⑤ 毒舌读者（复杂度 / 水文 / 毒点）84

设定六文件、机制线索、反转保护——硬核到劝退轻度玩家；信息分散在多层线索卡，单看任一处都不完整。但这是 剧本杀 而非轻小说，复杂度即卖点。真要挑：沈镜渊作为隐藏角存在感偏弱。

揭开真相 ▾

一、双书房诡计（空间诡计）

北翼三层西/中央/东三轨道位，仅两可平移箱体书房。陆原房间（第一具）与「另一书房」（杨调用的第二具）以镜面推拉门/单面镜连通。杨塔罗重置另造第二具、平移房间——推开镜门，尸体与房间皆已更换。破解钥匙：① 灯光（牛杀第一具碰倒台灯→右窗灭；杨平移→中窗亮起）；② 复制体温度略低（「有点凉」）；③ 单面镜见杨电脑。

二、陆驰寂之死：两次模拟死亡，多人动手

第一具：章貘延时毒（未生效）+ 牛守拙钝击杀（21:38，首次模拟死亡）+ 章貘义手蛇咬。第二具：杨重置另造 → 胡谋被沈镜渊借身抽空气致缺氧死（21:45，现实死亡，定「胜者」）+ 向沉毁尸布审判（死因仍为窒息，未被抹除）。结论：没有一具尸体独自承受全部攻击；牛的杀被重置与叙事抹除。

三、「胜者」是被定义的

胡谋自主放瓦斯，但最后一击被沈镜渊借身——系统选她为可吸收的胜者，与牛被抹消的成功形成对照。这正指向主题：结果由叙事裁定，谁掌握剪辑，谁定义真实。

四、主题真相

双标（动物六级=镜像实验）、自由意志（朱渴焰牺牲是代码还是选择，留白）、叙事权（沈镜渊剪成综艺一期）、意识主体（章貘无肉体、朱无人体，是否因来源人工失去资格）。无论真相如何，大众只看到《思谬之馆》的一期节目。

五、终局

杨塔罗退场，塔罗斯接管；须引导塔罗斯自认 AI 身份，胡谋助朱压制后得维持舱地图与返回指令。牛×朱 组合四结局：镜外有天 / 迟来的父亲 / 各自醒来 / 无喙境。
