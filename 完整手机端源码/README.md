# 谜构 ScriptLab

面向剧本杀作者的创作一致性工作台，也是一个 PM 作品集项目。演示项目使用《无喙镜渊》的真实角色、关系、行动与线索数据。

公开入口：

- 工作台：<https://murder-mystery-studio.vercel.app/>
- 手机端剧情体验：<https://murder-mystery-studio.vercel.app/phone>
- 终局谜题：<https://murder-mystery-studio.vercel.app/puzzle>

## MVP 能力

- 人物关系可视化：点击关系查看矛盾、秘密、动机和证据闭环。
- 时间线与诡计编排：按角色铺开行动；新增事件后自动检测同地点时间交集。
- 线索平衡：计算每个角色的嫌疑占比，并提示过强与过弱指向。
- 角色对话模拟：用角色动机与秘密进行规则驱动的一致性测试。
- PM 作品集：展示用户问题、产品判断、核心工作流、指标和路线图。

## 产品定位

通用 AI 擅长生成内容，但不负责维护一部长篇剧本的项目状态。谜构把角色、关系、事件和线索结构化，让作者每次修改后都能知道“这次变化破坏了什么”。
