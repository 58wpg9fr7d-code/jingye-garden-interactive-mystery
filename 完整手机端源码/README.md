# 静夜园 · 静夜园互动剧情

这是《静夜园》的完整手机端剧情体验源码，包含封面、角色本、分幕搜证、线索解锁、互动应用和终局解谜等前端体验。

公开入口：<https://murder-mystery-studio.vercel.app/phone>

## 当前能力

- 角色本与分幕剧情：按角色和剧情阶段控制信息释放。
- 线索搜证与解锁：支持线索抽取、收藏、公开和深层线索解锁。
- 互动应用：通过手机端应用、社交记录、新闻和终局谜题推进体验。
- 多结局体验：在关键节点保留玩家判断和终局选择。

## 说明

当前为手机端前端互动原型；角色解锁、线索推进和终局逻辑主要在前端运行，不应表述为实时多人后端或已接入大模型。
