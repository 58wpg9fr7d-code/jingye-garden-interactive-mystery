WUJING VECTOR MODEL / 无六骰·熵增立方
Version 2.1 / VISUAL ANAMORPHIC CONCEPT

注意：本文件用于说明美术概念与观察姿态，不是逐线施工图。网页可为了成像美感调整线条弯曲、抖动、疏密、透明度与局部位置，无须和每个坐标逐项对应。

定义
P(x,y,z) = 空间坐标点
V(Pa,Pb) = 连接两个坐标点的细线向量
旋转顺序 = yaw(Y) -> pitch(X) -> roll(Z)

核心规则
1. 骰子不是外置提示图，而是同一件三维雕塑的一部分。
2. 五个骰面由铰链连接，呈半展开状态；各面二面角分别约为 58°、43°、67°、51°，绝不铺平。
3. 第六面被撕除，只保留断裂铰链和九束悬空纤维。
4. 数字笔画不在任何平面上。每段线的端点深度 zA 与 zB 独立，且 zA != zB。
5. 观察与门上成像均使用中心透视，不使用正交投影；x、y、z 三个方向都会随深度产生透视缩放与汇聚。
6. 只有观察坐标经过指定旋转后，透视投影的端点才会对齐为数字；侧面观察仍是散乱空间线。

主线生成
每条屏幕笔画先定义二维目标端点 (x1,y1) -> (x2,y2)，再拆成：
[0,.25]、[.34,.62]、[.72,1]

每个断裂子段的端点深度：
zA = -1.15 + pseudo(face*101 + segment*17 + fragment*7 + 311) * 2.30
zB = -1.15 + pseudo(face*101 + segment*17 + fragment*7 + 487) * 2.30

随后对两个端点执行目标姿态的逆旋转，得到雕塑中的固定坐标：
Pa = inverseRotate(xA,yA,zA,targetPitch,targetYaw,targetRoll)
Pb = inverseRotate(xB,yB,zB,targetPitch,targetYaw,targetRoll)
V(Pa,Pb) = Pb - Pa

透视投影使用：factor = d / (d - z)，screen = (x * factor, y * factor)，其中 d = 5.6。
因此每条线真实穿过深度，标准姿态仅让它在透视投影中看似属于一个平面。

所有骰面边框、点数、断裂铰链与数字线使用同一旋转矩阵。每个标准姿态的俯仰或偏航角由对应骰面的真实二面角反推，并将滚转归零，保证该点数面端正面对观察者时，乱线才形成对应数字。

自动拍照判定
- 只要数字投影已经清晰成形，就立即拍照，不要求骰面完全正对观察者。
- 4 与 8 不限制画面内的滚转角度。
- 两个 6 为避免被误读为 9，数字底部必须大致朝下；允许相对竖直方向偏转 55°，不要求完全垂直于地面。
